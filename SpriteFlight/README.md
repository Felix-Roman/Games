Sprite-Flight:
Here is another game that I have been working on recently!

Through completing this 2D game in Unity, I gained hands on experience with core game development concepts and tools. This project helped me understand both the technical and creative aspects of building a simple 2D game from start to finish.

What I Learned:
-Working in the Unity Editor
-Navigating scenes, GameObjects, and components
-Using sprites and 2D assets effectively
-Adjusting transforms for positioning and scaling
-Understanding the Inspector and serialized variables

Core Gameplay Programming:
-Handling player input for movement and actions
-Implementing collision detection using 2D colliders
-Creating simple game mechanics such as avoiding obstacles and collecting items
-Managing game states like start, play, and game over

Physics and Interaction:
-Using Rigidbody2D for movement and physics behavior
-Detecting collisions and triggering events
-Understanding how physics influences gameplay feel
-Activity Description

During this process, I created and configured GameObjects, applied components such as colliders and rigid bodies, and wrote C# scripts to control gameplay behavior. I also worked with Unity’s UI system to display basic game information and feedback to the player such as their score. By the end of this, I had a fully playable 2D game that demonstrated core mechanics like movement, collision, and scoring.

Technical Decisions:
-Throughout this project, I made several important technical decisions. First, I chose to rely on Unity’s built-in 2D physics system (Rigidbody2D and colliders) -rather than manually coding movement and collision detection. This allowed for more efficient development and more realistic interactions.
-I also structured my scripts to separate responsibilities, such as handling player input, game logic, and collision responses in different components. This improved code readability and maintainability.
-Another key decision was to use prefabs for reusable objects like obstacles. This made it easier to manage and spawn multiple instances while maintaining consistency. Additionally, I used serialized fields to expose variables in the Inspector, allowing for quick adjustments without modifying code.

Reflection:
-This project helped me build a strong foundation in Unity and 2D game development. I learned how different systems such as physics, input, and UI work together to create a functional game. It also improved my problem solving skills, especially when debugging issues related to collisions and object behavior.
-Moving forward, I plan to apply these skills to more advanced projects, including adding more complex mechanics, improving game design, and exploring AI or procedural systems. This experience has given me confidence in using Unity and has prepared me for developing more interactive and engaging games.
